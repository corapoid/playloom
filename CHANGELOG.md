# Changelog

## 0.0.3 - 2026-08-25

- Added RSS 2.0 podcast feed loading with iTunes metadata, shareable feed URLs, and inline waveform detection.
- Added optional season filtering for feeds with multiple `itunes:season` values.
- Added configurable audio/video mode and switch visibility.
- Refined the mobile load-more button and playback controls with liquid-glass styling.

## 0.0.2 - 2026-08-25

- Added Polish and English localization for the configurator and player.
- Added a language selector with URL and generated-config support.

## 0.0.1 - 2026-08-25

- Initial release of the podcast player and configurator.
